# TP2 - Metodología de Sistemas II

Repositorio grupal para el Trabajo Práctico 2 de Metodología de Sistemas II.

## Estructura del código

```text
src/main/java/
├── patrones/
│   ├── strategy/   # Persona 1
│   ├── adapter/    # Persona 2
│   └── template/   # Persona 3
├── refactoring/    # Persona 5
└── Main.java       # Persona 6 (integración)
```

La Persona 4 desarrolla el análisis teórico de Refactoring para el documento PDF.

## Reglas de trabajo

- Cada integrante debe trabajar en una rama propia.
- Modificar únicamente los archivos correspondientes a la tarea asignada.
- No trabajar directamente sobre `main`.
- Antes de integrar cambios, actualizar la rama propia con `main`.
- Subir los cambios a GitHub y abrir un Pull Request hacia `main`.
- No modificar ni borrar archivos de otros integrantes.
- La integración final y las pruebas generales se realizan desde `main`.

## Proyecto

Proyecto Java de Apache NetBeans. La carpeta de código fuente está configurada en `src/main/java`.
