# TP2 - Metodología de Sistemas II

Repositorio grupal del Trabajo Práctico 2. El código Java del proyecto se compila desde `src/main/java` y se ejecuta mediante `Main.java`.

## Estructura por actividad

```text
src/main/java/
├── Main.java                              # Integrador de las demostraciones disponibles
├── patrones/
│   ├── strategy/                          # Actividad 1: Strategy
│   ├── adapter/                           # Actividad 2: Adapter
│   ├── template/                          # Actividad 3: Template Method
│   ├── observer/                          # Actividad 4: pendiente de implementación
│   └── gestionheroes/                     # Actividad 5: Factory Method, Singleton y Facade
└── refactoring/                           # Sección de Refactoring
    ├── Habilidad.java
    ├── HabilidadCuerpoACuerpo.java
    ├── HabilidadMagica.java
    ├── Personaje.java
    └── Videojuego.java
```

`Main` ejecuta cada módulo disponible por separado. La actividad 4 (Observer) se indica como pendiente hasta que sus clases estén en el repositorio.

## Ejecución

En NetBeans, ejecutar el proyecto para iniciar `Main`.
